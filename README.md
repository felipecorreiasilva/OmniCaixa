# OmniCaixa# 🛒 OmniCaixa Mobile

Aplicação mobile de Frente de Caixa (PDV) e Gestão de Estoque desenvolvida para complementar o ecossistema OmniCaixa, garantindo total paridade funcional com a versão web.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:
* **React Native** com **Expo** (Expo Router)
* **NativeWind** (Tailwind CSS para React Native)
* **TypeScript**
* **Expo Image Picker** (Gestão e seleção de imagens nativas)
* **Lucide React Native** (Ícones)

## ✨ Funcionalidades

* **Frente de Caixa (PDV)**: Carrinho de compras, cálculo dinâmico de itens, suporte a produtos por unidade ou peso (kg) e múltiplas formas de pagamento (Dinheiro com cálculo de troco, Cartão e Pix).
* **Gestão de Produtos**: Listagem otimizada por cards, pesquisa em tempo real, cadastro, edição e exclusão de produtos com suporte a upload de imagens.
* **Controlo de Acessos (RBAC)**: Proteção de rotas com base em cargos (`admin`, `manager`, `cashier`).
* **Tema Dark (Zinc)**: Interface moderna e padronizada em tons escuros.

## ⚙️ Pré-requisitos

Certifica-te de que tens instalado no teu computador:
* **Node.js** (versão LTS recomendada)
* **npm** ou **yarn**
* **Expo Go** instalado no teu telemóvel (ou um emulador configurado).
